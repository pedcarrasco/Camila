# 🧸 Sorpresa Especial de Cumpleaños para Camila 💖🌹

Una aplicación web de una sola página (Single Page Application - SPA) responsiva, romántica y de estilo kawaii creada con React, Vite y Tailwind CSS.

---

## 🚀 Despliegue en Vercel y GitHub

### Paso 1: Subir el proyecto a GitHub
1. Crea un nuevo repositorio en [GitHub](https://github.com/new) (por ejemplo: `cumpleanos-camila`).
2. En tu terminal dentro de la carpeta del proyecto, ejecuta:
   ```bash
   git remote add origin https://github.com/TU_USUARIO/cumpleanos-camila.git
   git push -u origin main
   ```

### Paso 2: Conectar y desplegar en Vercel
1. Ve a [Vercel](https://vercel.com) e inicia sesión con tu cuenta de GitHub.
2. Haz clic en **"Add New..."** → **"Project"**.
3. Selecciona tu repositorio `cumpleanos-camila` e impórtalo (**Import**).
4. Vercel detectará automáticamente **Vite** como framework:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
5. Haz clic en **"Deploy"**. En menos de un minuto tu web estará activa y con enlace HTTPS personalizado listo para compartir con Camila.
